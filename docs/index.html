How it works

Three steps. Zero config.

1
Scan

Extract

Scripts extract classes, imports, TODOs, git history. AI reasons about architecture and behavior.

# Script-backed python3 scan_ast.py → ast.json python3 scan_imports.py → deps.json bash scan_git.sh → git.txt # AI-backed AI reasons architecture → sequence.mmd
2
Chart

Generate

Generate Mermaid .mmd files organized by layer: structure, behavior, data, project, quality.

.flowmem/ structure/ modules.mmd classes.mmd behavior/ auth_flow.mmd data/ schema.mmd project/ roadmap.mmd quality/ debt.mmd
3
Traverse

Query

AI loads only relevant charts per question. Script-backed charts refresh on demand for live data.

"How does auth work?" → load behavior/ charts "Where is tech debt?" → load quality/debt.mmd "Refresh data" → run refresh_all.sh

Open Source Apache 2.0

A Mermaid-powered visual canvas editor — the best way to view, edit, and share FlowMem charts visually. Built for low-code users and developers who want to work with Mermaid diagrams interactively.

  • → Paste any .mmd file from .flowmem/charts/ to view it visually
  • → Click nodes to select, change shapes, add colors, export SVG/PNG
  • → Built with React + Zustand + mermaid.js — runs 100% in the browser
  • → Optional companion to FlowMem — FlowMem works great without it

Install in 10 seconds

FlowMem is a Claude Code skill. Copy it into your project or global skills directory.

Option A — Per-project
# From your project root mkdir -p .claude/skills cp -r /path/to/flowmem .claude/skills/flowmem
Option B — Global (all projects)
cp -r /path/to/flowmem ~/.claude/skills/flowmem
Then trigger in Claude Code
# Any of these phrases work: "generate flowmem for this project" "build memory charts" "index this codebase as mermaid" "create mermaid memory"
