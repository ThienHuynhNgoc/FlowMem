# FlowMem Traversal Guide — flowmem

This guide helps an AI coding assistant navigate the FlowMem memory system
for the **flowmem skill project itself**.

---

## Project Overview

FlowMem is a Claude Code skill with three operation modes (Generate, Refresh, Traverse).
It extracts codebase knowledge using 8 scripts and stores it as Mermaid `.mmd` files
in a `.flowmem/` directory, organized into 5 layers (structure, behavior, data, project, quality).

Key files: `SKILL.md` (entry point), `references/` (4 guides), `scripts/` (8 extractors),
`templates/` (18 templates).

## Refresh Commands

```bash
# Script-backed charts — refresh before reading:
python3 .flowmem/scripts/scan_todos.py > .flowmem/.cache/todos.json   # → debt.mmd
python3 .flowmem/scripts/scan_metrics.py > .flowmem/.cache/metrics.json # → complexity.mmd
bash .flowmem/scripts/scan_files.sh > .flowmem/.cache/files.txt         # → distribution.mmd

# Full refresh:
bash .flowmem/scripts/refresh_all.sh
```
